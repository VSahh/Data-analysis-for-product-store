# Аналіз даних продуктового магазину

## Огляд проєкту
У цьому проєкті проведено аналіз даних продуктового магазину за допомогою Python.

Файл містить:
- очищення даних,
- об’єднання таблиць,
- дослідницький аналіз даних (EDA),
- візуалізацію даних,
- пошук бізнес-інсайтів щодо ревеню, профіту, категорій товарів, регіонів, каналів продажу та часу доставки.

## Дані
Аналіз базується на трьох CSV-файлах:

- `events.csv` — дані про замовлення
- `countries.csv` — інформація про країни та регіони
- `products.csv` — інформація про товари та категорії

## Основні етапи аналізу
1. Імпорт та підготовка датасетів
2. Очищення назв колонок у формат `snake_case`
3. Перетворення дат у формат datetime
4. Обробка пропущених значень
5. Об’єднання таблиць в один dataset
6. Розрахунок:
   - revenue
   - cost
   - profit
7. Аналіз:
   - категорій товарів
   - країн та регіонів
   - каналів продажу
   - часу доставки
   - динаміки по роках, місяцях та днях тижня

## Використані технології
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Основні висновки
- Загальна кількість замовлень: 1330
- Загальний revenue: 1,704,628,370.65
- Загальний profit: 501,842,633.12
- Найприбутковіші категорії:
  - office supplies
  - household
  - cosmetics
- Найбільший profit генерує Europe
- Online та offline продажі мають близькі показники
- Сильного зв’язку між часом доставки та profit не виявлено
- Profit зростав до 2012 року, після чого почав знижуватись
